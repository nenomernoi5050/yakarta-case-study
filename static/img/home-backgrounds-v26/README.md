# Variant 26 homepage backgrounds

This directory contains decorative section backgrounds for the Yakarta homepage.
They are loaded only by `/static/css/home-backgrounds-v26.css`.

Expected files:

| File | Homepage section |
|---|---|
| 01-hero-workspace.webp | Hero / workspace and interfaces |
| 02-cases-analytics.webp | Cases / analytics and dashboards |
| 03-support-monitoring.webp | Support / servers and monitoring |
| 04-services-modules.webp | Services / lifecycle and modules |
| 05-problems-incident.webp | Urgent help / incident response |
| 06-showcase-prototype.webp | Prototype / UX and interface mockups |
| 07-responsibility-team.webp | Responsibility / technical team |
| 08-pricing-integrations.webp | Pricing / modules and integrations |
| 09-blog-workspace.webp | Blog / expert workspace |
| 10-faq-support.webp | FAQ / support and answers |

Integration rules:
- Decorative only: no HTML structure, copy, forms, JavaScript, or business logic changes.
- Use optimized WebP assets.
- Desktop target currently prepared at 1200×675.
- CSS includes readability overlays and mobile positioning.
- Production remains unchanged until this branch is reviewed and merged.
